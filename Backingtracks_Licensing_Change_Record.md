## 2. Repository licensing change

The repository previously contained a root-level file named `LICENSE` that identified the material as CC0-1.0. The rights holder removed that file from the current `main` branch.

The commit message used for the removal was:

> Remove superseded CC0 licence file

The repository retains `LICENSE.md`, which sets out the intended terms for personal/noncommercial use and commercial permissions where the relevant rights holder controls the rights. The README was also updated to link to `LICENSE.md`.

The rights holder states that `Credits.txt` and/or `Credits.nfo` files were intentionally created for track packs and left blank. Those files did not state a specific credit or attribution requirement.

This records how the files were prepared; it does not by itself establish the legal effect of any separate licence.

Removing the old `LICENSE` file changes the current repository contents. It does **not automatically revoke rights that may already have been granted under an earlier CC0 licence**. The legal effect of the earlier licence depends on the material covered and the circumstances of its publication.

This document records the rights holder's stated position and repository changes. It is not a legal opinion or a finding that earlier permissions have been revoked.
